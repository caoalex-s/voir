# Publication figures

**Extended figure set, 26 October 2026:** these exports include the corrected ductile-force calculation, the same prescribed loading condition for intact and attacked systems, every initial damage outcome, and deterministic evaluation of probabilities lost to the original numerical cap. The $\pi$ limit is used only for display. Figure 6 covers $r=1,\ldots,9$; Figure 7 retains $r=1,\ldots,7$ for readability. These files accompany the proof amendments and supersede the earlier exports.

The numerical figures accompanying the [paper](https://doi.org/10.1016/j.strusafe.2026.102773) are produced by [publication_walkthrough.m](../../publication_walkthrough.m) and the same callable pipeline.

Use the individual files for the manuscript's LaTeX subfigure environments. Captions and subfigure letters are supplied by LaTeX, rather than embedded in these panel files. PDF and SVG are vector formats; PNG files provide quick previews.
